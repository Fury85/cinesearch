About CineSearch

A fast, accessible movie discovery app — search titles, explore by theme, read full plots, and save favourites in your browser.

Features

  • Search movies via the OMDB API
  • Genre chips combine with your search (e.g. “nolan” + Sci-Fi)
  • Detail panel with plot, runtime, genres, and IMDb link
  • Favourites saved in localStorage — no account required
  • Responsive layout, keyboard support, and screen-reader labels

Tech stack

Vanilla HTML, CSS (design tokens + component modules), and JavaScript — no frameworks, no build step required.
